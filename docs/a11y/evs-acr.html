Notes

Generated by evs-acr-gen (tools/acr) from (1) the OpenACR catalog 2.5-edition-wcag-2.1-508-en.yaml, (2) axe-core results collected by @axe-core/playwright across every EVS route, viewport (360, 768, 1280, 1920 px), theme (light, leadership) and prefers-reduced-motion setting, (3) Lighthouse CI and pa11y-ci runs, (4) Playwright keyboard-traversal and 320 px reflow smoke tests and (5) the manual attestation file docs/a11y/manual_attestation.yaml. A row is "supports" only when every automated cell passes and the manual attestation says supports; "not-evaluated" means evidence is missing and no claim is made. Only the Web component is evaluated; Electronic Documents, Software (Chapter 5) and Authoring Tools are reported Not Applicable because EVS is a web application evaluated against WCAG. Target: WCAG 2.1 Level AA plus Revised Section 508. WCAG 2.2 criteria 2.4.11, 2.5.7 and 2.5.8 are tracked as design rules outside this report. EVS is a demonstration system; this report describes the demo build, not a production deployment. Evidence in this build: 192 axe cells, 0 gating violations, 11 Lighthouse runs, 12 keyboard smoke routes, 24 reflow cells, 9 attested rows; commit 97ec213ac054. WCAG 2.1 A/AA rows: 4 supports, 0 partially supports, 0 does not support, 5 not applicable, 39 not evaluated.

Evaluation methods used

Automated: axe-core via @axe-core/playwright in CI (every route x 4 viewports x 2 themes x reduced-motion on/off), eslint-plugin-jsx-a11y strict, Lighthouse CI accessibility category (budget 100), pa11y-ci (axe runner, WCAG2AA), Playwright keyboard-traversal and 320 px reflow smoke tests. Manual: keyboard-only pass, NVDA + Firefox, JAWS + Chrome, VoiceOver iOS + Safari, 200% and 400% zoom / 320 CSS px reflow, Windows High Contrast (forced-colors), colour-vision deficiency simulation, prefers-reduced-motion. Manual test IDs (MT-*) refer to docs/a11y/MANUAL_TEST_PLAN.md.
