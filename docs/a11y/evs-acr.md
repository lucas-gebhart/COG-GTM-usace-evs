## Evaluation methods used

Automated: axe-core via @axe-core/playwright in CI (every route x 4 viewports x 2 themes x reduced-motion on/off), eslint-plugin-jsx-a11y strict, Lighthouse CI accessibility category (budget 100), pa11y-ci (axe runner, WCAG2AA), Playwright keyboard-traversal and 320 px reflow smoke tests.
