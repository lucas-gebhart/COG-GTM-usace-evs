# The "before" side: APEX pages in the migration slice

This folder documents the eight Oracle APEX Strategic Planner pages the EVS demo migrates. It is
demo material about the legacy application; EVS itself does not exist in production.

APEX pages render only inside an Oracle database with the APEX engine, so there is no static
render of the export. `pages.md` (generated by `make inventory` from the export, never edited by
hand) carries the page definition for each slice page instead: title, mode, page group,
authorization scheme, every region with its type and the `SP_` objects its SQL touches,
Interactive Report column counts, chart series, visible items, processes and dynamic actions.
Put real screenshots here (`page_<n>_<slug>.png`) if an APEX workspace becomes available; the
Oracle starter-app gallery at https://apex.oracle.com/go/strategic-planner shows the live app.

## Page to route map

| APEX page | APEX name (page group) | What the user sees in APEX | EVS route | EVS page |
|---|---|---|---|---|
| 1 | home (Home) | Dashboard: My Projects, My Initiatives, My Activities, My Open Releases cards; Recently Changed Projects report; notifications and reviews needed | `/` | Enterprise overview: KPI tiles, schedule health, freshness strip |
| 21 | Initiatives (Initiatives) | Faceted search over initiative cards (`sp_initiatives`, `sp_areas`) | `/programs` | Programs and portfolio table with variance bars |
| 3 | Project Details (Projects) | Project header, Milestones, Tasks, Reviews, Contributors, Documents, Links, Comments, Activity, Approvals; 7 Interactive Reports | `/projects/:p2` | Project detail: milestone timeline, obligations burn, labor hours, CMP records, documents |
| 74 | People (Users) | Faceted search over people cards with activity rollups | `/workforce` | Workforce and labor (EMS) bullet charts and labor table |
| 4 | Kanban Board | Faceted search plus a classic report rendered as a Kanban board over `sp_projects` by status | `/schedule` | Schedule and lifecycle (P2 / CMP) Gantt with list alternative |
| 10000 | Administration (Administration) | Two-column list page: Look Up Values, Approval Options, Configuration, Monitoring, Access Control; guarded by the Administration Rights scheme | `/admin` | Data feeds and thresholds (requires `evs_admin`) |
| 86 | Projects (Reporting) | Projects Interactive Report, 50 columns, over `sp_projects` and its lookups | `/projects` | Projects table (sortable, filterable, downloadable) |
| 161 | Cumulative Flow | JET area chart over `sp_project_history` and `sp_projects` | `/financial` | Financial execution (CEFMS) cumulative line with plan band and table alternative |

`docs/PLAN.md` section 11 lists the slice as "Dashboard charts, Initiatives IR, Project Details
form, People IR, Kanban board, Admin/lookups, Projects IR and one JET chart region". The export
has no chart on the home page (page 1 is cards and classic reports) and the Initiatives and
People pages are faceted-search card reports rather than Interactive Reports, so the chart row
uses page 161, the only cumulative JET chart in the application. `legacy/mapping.json` is the
source of truth for this table; `legacy/traceability.csv` carries it per region.
